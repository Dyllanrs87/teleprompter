# TP Roteiros

Teleprompter simples para gravar vídeos, em um único arquivo (`index.html`). Funciona no navegador do computador e do celular, sem instalar nada.

## Como usar

1. Cole o roteiro (ou abra um `.txt`).
2. Ajuste velocidade, fonte, espelhamento e contagem regressiva.
3. Toque em **▶ Iniciar leitura**.

## Modos de rolagem

- **Velocidade fixa:** rola na velocidade escolhida.
- **🎤 Rola enquanto eu falo:** anda enquanto há voz e para no silêncio (ajuste a sensibilidade pelo medidor).
- **🎤 Acompanha as palavras:** reconhece a fala e mantém a próxima palavra na linha de leitura.

Os modos de voz precisam de permissão de microfone e de um endereço `https` (por isso o site fica no GitHub Pages). No iPhone, o modo "acompanha as palavras" exige o Ditado ativado em Ajustes.

## Marcações no roteiro

- `[texto entre colchetes]` aparece em amarelo: indicações de gravação, não são lidas.
- `*texto entre asteriscos*` aparece em vermelho: ênfase.

O roteiro fica salvo só no navegador de cada aparelho; nada é enviado para o site.
